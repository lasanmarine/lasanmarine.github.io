From operating requirements to a design that can move forward

We design newbuilds and vessel conversions, and we take on specialist calculations where a full design package is not required. The work can cover principal dimensions, hull form, hydrostatics, stability, resistance, structures, propulsion and technical drawings.

Different projects need different levels of design support

A new vessel, a conversion and a single calculation do not need the same scope. We start from the operating goal and the information already available, then define the work that actually needs to be done.

I need a new vessel concept from an operating brief

The vessel type, mission, operating area or key constraints are known, but there is not yet a complete technical concept.

Hướng xử lý

We develop the principal dimensions, hull form, general arrangement, structure and propulsion concept from the operating requirements, then carry the agreed design into the calculations and drawings needed for the next stage.

Build a design brief

An existing vessel needs to be lengthened, reconfigured or repowered

Changes to dimensions, loading, layout or equipment can affect stability, structures and onboard systems.

Hướng xử lý

We review the available drawings and vessel condition, identify the areas affected by the proposed change, and define the calculations and drawings that need to be updated.

Discuss a conversion

I only need one calculation or design check

The project already has a design, but a specific question remains around stability, resistance, power, propellers, shafting or structural strength.

Hướng xử lý

We can take on a defined calculation package without rebuilding work that is already complete, giving the project the technical evidence needed to make the next decision.

Send the calculation brief

I already have drawings and need missing technical work completed

Part of the design package exists, but some calculations, drawings or supporting documents are still missing.

Hướng xử lý

We review the existing material, identify the gaps and complete the agreed technical work so the project can continue without duplicating what has already been done.

Send existing drawings

Know what will be delivered before the work starts

A project may need a complete design package or only a defined group of calculations and drawings. We agree the deliverables up front so the client knows what is included, what is not, and how the output can be used in the next stage of the project.

  • Hydrostatics, stability, resistance, structural and propulsion calculations within the agreed scope
  • General arrangement, structural, system and detail drawings
  • Technical notes, manuals, as-built drawings and supporting documentation
  • Revisions and technical coordination for the work we deliver

How the work moves forward

01
Review the brief and available information
We look at the operating requirements, existing drawings and the intended use of the final output, then agree the work that needs to be done.
02
Develop and check the design
Principal dimensions, hull form, arrangement and the key design calculations are checked before the project moves deeper into detailed documentation.
03
Complete calculations and drawings
We develop the agreed calculations and drawings, keeping assumptions, inputs and design decisions traceable.
04
Coordinate revisions and project feedback
We update the work we have delivered when technical feedback or project changes affect the agreed design scope.
